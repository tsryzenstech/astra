# Development setup

astraOS runs unmodified on a desktop Linux machine (or WSL2): the whole
filesystem is relocated under `ASTRA_ROOT`, SysBoard runs as a window and
apps connect to it over Wayland.

## Dependencies

Debian/Ubuntu:

```bash
sudo apt install build-essential cmake ninja-build pkg-config python3 libdrm-dev libpng-dev zlib1g-dev
```

Qt ≥ 6.5 with the Wayland Compositor, Multimedia and Svg modules. If your
distribution ships an older Qt, install one with
[aqtinstall](https://github.com/miurahr/aqtinstall):

```bash
python3 -m pip install aqtinstall
aqt install-qt linux desktop 6.8.3 linux_gcc_64 -m qtwaylandcompositor qtmultimedia -O ~/Qt
```

## Run

```bash
QT_DIR=~/Qt/6.8.3/gcc_64 scripts/dev-run.sh
```

| Key / action | Effect |
|---|---|
| F12 | power key (lock / screen off) |
| drag up from the bottom | unlock, close apps |
| drag down from the top left / right | Notification / Control Center |

`ASTRA_HEADLESS=1 scripts/dev-run.sh` runs on a virtual X display (needs
`Xvfb`). While it runs, `scripts/dev-ctl.sh` drives it:

```bash
scripts/dev-ctl.sh swipe 196 700 196 250 180   # unlock
scripts/dev-ctl.sh tap 335 581                 # open Settings
scripts/dev-ctl.sh screenshot /tmp/settings.png
```

State lives in `out/root/data`; delete it to get a first boot again.

## Tests

```bash
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH=$QT_DIR
cmake --build build
ctest --test-dir build --output-on-failure
```

| Test | Covers |
|---|---|
| `apkgtool` | packing, reproducibility, tamper detection, manifest validation, all system apps |
| `apkg_reader` | the C++ reader against packages built by apkgtool |
| `spring` | the AnimationEngine solver (settling, overshoot, analytic velocity) |
| `init_rc_parses` | every `.rc` file shipped by the system |

## Icons

The symbolic icon set (`frameworks/qml/controls/icons`) is generated by
`tools/icons/generate_icons.py`; edit the script, not the SVGs.
